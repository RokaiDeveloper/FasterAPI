# Security Policy

---

**[Português (Brasil)](#português-brasil)**

## Supported versions

Security fixes are evaluated against the latest published FasterAPI version.
Older versions may not receive fixes. Upgrade to the latest compatible release
before reporting an issue.

## Reporting a vulnerability

Do not report suspected vulnerabilities through public Issues, Discussions, or
Pull Requests.

Use GitHub's private vulnerability reporting feature:

**Security → Advisories → Report a vulnerability**

If private reporting is unavailable, contact the repository maintainer through
the private contact method listed on the maintainer's GitHub profile and do not
include sensitive information in a public issue.

Please include:

- affected FasterAPI version;
- Java, Spring Boot, and database versions;
- impact and attack scenario;
- steps to reproduce;
- a minimal proof of concept, when safe;
- suggested mitigation or fix, if known.

Do not include real credentials, access tokens, private keys, personal data, or
production data. Replace them with synthetic values.

## Disclosure process

Reports are reviewed privately. The maintainer may request additional details,
coordinate a fix, and publish a security advisory after a fix or mitigation is
available. There is no guaranteed response or remediation timeline.

Security reports and fixes remain subject to the
[FasterAPI Proprietary Free-Use License](LICENSE).

# Português (Brasil)

## Versões suportadas

Correções de segurança são avaliadas contra a última versão publicada do FasterAPI. Versões mais antigas podem não receber correções. Atualize para a versão compatível mais recente antes de relatar um problema.

## Relatando uma vulnerabilidade

Não relate vulnerabilidades suspeitas através de Issues públicas, Discussions ou Pull Requests.

Use o recurso de relatório de vulnerabilidade privada do GitHub:

**Security → Advisories → Report a vulnerability**

Se o relatório privado não estiver disponível, entre em contato com o mantenedor do repositório através do método de contato privado listado no perfil do GitHub do mantenedor e não inclua informações sensíveis em uma issue pública.

Por favor, inclua:

- versão do FasterAPI afetada;
- versões do Java, Spring Boot e banco de dados;
- impacto e cenário de ataque;
- passos para reproduzir;
- um conceito de prova mínimo, quando seguro;
- mitigação ou correção sugerida, se conhecida.

Não inclua credenciais reais, tokens de acesso, chaves privadas, dados pessoais ou dados de produção. Substitua-os por valores sintéticos.

## Processo de divulgação

Relatórios são revisados privadamente. O mantenedor pode solicitar detalhes adicionais, coordenar uma correção e publicar um aviso de segurança após uma correção ou mitigação estar disponível. Não há garantia de resposta ou cronograma de remediação.

Relatórios de segurança e correções continuam sujeitos à [FasterAPI Proprietary Free-Use License](LICENSE).
